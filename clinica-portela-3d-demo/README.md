# Clínica Portela — Demo 3D

Demonstração de landing page premium com:
- objeto 3D procedural feito com Three.js;
- interação suave com o mouse;
- animações de entrada;
- WhatsApp funcional;
- Google Maps;
- seção de tecnologia/IA;
- responsividade para celular.

## Como executar

Abra a pasta no VS Code e abra `index.html` no navegador.

Para uma experiência melhor, pode usar a extensão Live Server do VS Code.

## Arquivos

- `index.html` — estrutura da página.
- `css/style.css` — design responsivo.
- `js/main.js` — WhatsApp, menu, animações e Three.js.

## Observação

O 3D deste exemplo é criado por código, portanto não é necessário baixar um modelo `.glb`.

O mapa usa o CEP/localização informada na demonstração. Antes de publicar, confirme o endereço completo da clínica.
